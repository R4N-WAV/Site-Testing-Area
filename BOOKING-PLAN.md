# Booking: plan and progress

Working notes for the /booking page, so the work can be picked up again at any point.
Work happens in this repo (Site-Testing-Area), pushed to `main` after every step. The live site
(R4N-SITE) is only updated when everything is done and tested (copy everything except CNAME).

## What R4N asked for
- Clicking BOOKING: the site dives down the tunnel and the whole thing inverts (black background,
  slightly lighter logo, readable light buttons). So smooth you don't notice it's a new page.
  The address becomes /booking/; opening /booking/ directly shows the booking page straight away.
- On arrival: a 3D passport, exactly like the red Norwegian passport (reference photo), large,
  not distorted. Changes only: the crest's lion becomes a "51" that fills the shield like a logo,
  in the same engraved style (crown stays); "NORGE NOREG" becomes "R4N"; "BOOKING" where
  "PASS / PASSPORT" was; NORWAY line removed; chip symbol kept. Real leather texture, gold foil.
- Motion: every 3-5 s it shakes and bounces a little, as if something inside wants out.
- Glow: warm golden light leaking from the edges (like the glowing book photo), live and moving,
  not a static texture.
- Later (not now): clicking the passport opens it (live shows, photos, booking link).
- instagram / spotify / contact visible at the very bottom on every page, always
  (same look as in the opened record).

## Decisions
- One app: `booking/index.html` is the same page as `index.html` with `<base href="../">`, so all
  paths work from /booking/. Generated by `scripts/sync-pages.mjs` (run after editing index.html).
- The transition: tunnel warps forward (existing warp "out"), the root gets `filter: invert()`
  animated 0 -> 1, then swaps to the real dark theme (`body.booking`), same look, filter off.
  Back (logo or "← R4N", or browser back): the reverse.
- The passport: its own module `js/booking.js` and canvas, made on first use. Three.js;
  textures drawn in code (leather grain, gold foil, crest, text) with font Cinzel (OFL, in
  assets/fonts). Glow: emissive page edges + animated light-ray shader + bloom.
- Socials: one fixed footer `#socials` for the whole site; hidden while a record is open
  (the record shows its own in the same place).
